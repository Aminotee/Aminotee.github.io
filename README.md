# Aminotee — Jazz & Lounge Pianist

Portfolio website for Aminotee, a jazz and lounge pianist performing in hotels,
restaurants and private events — featuring a repertoire of 63 songs across jazz standards, sentimental
classics, smooth lounge, classical, Andalusian/Arabic music and special
occasions.

Built as a single self-contained `index.html` (no build step), served via
GitHub Pages at [aminotee.github.io](https://aminotee.github.io).
